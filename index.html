PEC 3: Tutorial de A-FRAME 360º

UOC - Realidad virtual (semestre 2627/1)

Alejandro Fuentes Pérez

Usa el ratón o arrastra para rotar la vista 360º. En móvil, orienta el dispositivo para explorar la escena.

Nota: los vídeos 360º requieren interacción de usuario para iniciar la reproducción debido a políticas del navegador.

Requisitos del proyecto (PEC3)

  • 🔄 Escena 1 - Fondo panorámico 360º fijo (<a-sky>) Integración de imagen equirrectangular 360º con elementos interactivos y animados.
  • 🔄 Escena 2 - Fondo panorámico 360º en vídeo (<a-videosphere>) Integración de clip de vídeo equirrectangular optimizado en formato MP4 con control de reproducción.
  • ✅ Estructura de entrega y carpetas Página raíz index.html y subcarpeta recursos/ para el resto de archivos y assets.
  • ✅ Incrustación en documento HTML Uso de <iframe> conforme al paso 7 del tutorial para integrar ambas escenas en una interfaz web.
  • ✅ Límite de tamaño (< 10 MB) Optimización exhaustiva de medios 360º para asegurar un empaquetado inferior a 10 MB.
